# 井下燃气阀门监测控制系统 (JingXiaxianmu)

基于 **STM32L496 + RT-Thread** 的井下燃气阀门智能执行器控制固件。

> ⚠️ 本项目为**学习/参考**用工程，未做任何功能安全认证，**禁止直接用于实际燃气管道**。

---

## 功能概览

- **阀门开度闭环控制** —— 绝对值编码器反馈 + 无刷电机正反转（Bang-Bang + 迟滞，机械大减速比本身即减速段）
- **双路压力采集** —— 2 路 4~20mA 电流环，量程 0~30MPa
- **过载保护** —— 压力超限立即停机、记录超压方向与峰值、把目标角度锁定为当前角度（防止停机后压力消失导致闭环自动重启的"启停启停"振荡）
- **阀杆老化 / 卡滞检测** —— 运行中压力"持续"达到标称值的 130% 判定故障（漏桶计数，滤掉顶极限瞬间的冲击尖峰）
- **Modbus RTU 双角色** —— 对编码器做主站（U2），对上位机/PLC 做从站（U3）
- **msh 命令行** —— 现场调试、参数标定、故障复位

## 压力换算

```
P(0.01 MPa) = (ADC - 596) × 3000 / (2978 - 596)
```

- `ADC = 596` → 4mA → 0 MPa
- `ADC = 2978` → 20mA → 30.00 MPa
- `ADC < 596` 可视为断线 / 回路未通

ADC 采样为 12 位，使用 DMA + 一阶低通滤波（α = 64/256）。

## Modbus RTU 协议（U3，从站地址 01）

**数据大端；CRC16（多项式 0xA001，初值 0xFFFF），低字节在前传输。**

### 读保持寄存器（功能码 0x03）

| 寄存器 | 偏移 | 名称 | 单位 / 说明 |
|---|---|---|---|
| 40001 | 0x0000 | 当前角度 | 0.1° |
| 40002 | 0x0001 | 压力 1 | 0.01 MPa |
| 40003 | 0x0002 | 压力 2 | 0.01 MPa |
| 40004 | 0x0003 | 报警字 | 0=正常 1=锈蚀/老化 2=泄漏 3=过载 |
| 40005 | 0x0004 | 最近一次过载方向 | 0=无/停机 1=开阀(CW) 2=关阀(CCW) |
| 40006 | 0x0005 | 过载事件峰值 P1 | 0.01 MPa |
| 40007 | 0x0006 | 过载事件峰值 P2 | 0.01 MPa |
| 40011 | 0x000A | 阀门状态 | 0=停止 1=开阀 2=关阀 |
| 40012 | 0x000B | 当前开度 | 0.1°（900 = 90.0°） |
| 40013 | 0x000C | 硬件版本 | — |
| 40014 | 0x000D | 软件版本 | — |

### 写单寄存器（功能码 0x06，成功应答 = 原帧回显）

| 寄存器 | 偏移 | 作用 | 说明 |
|---|---|---|---|
| 40002 / 40011 | 0x0001 / 0x000A | 开 / 关 / 停阀 | 写 1=开阀、2=关阀、0=停止 |
| 40010 | 0x0009 | 目标开度 | 单位：度，自动钳位到当前阀门配置范围 |
| 40016 | 0x000F | 过载故障复位 | 写 1 清除过载故障与保持状态 |

### 报文示例

```
读当前数据(40011~40014)
发送: 01 03 00 0A 00 04 64 0B
应答: 01 03 08 00 01 03 84 00 01 00 01 E5 3A

开阀
发送: 01 06 00 01 00 01 19 CA
应答: 01 06 00 01 00 01 19 CA
```

## 阀门配置

两套参数可运行时切换（msh 命令 `ValveCfg Big|Small`），本工程默认 `Small`：

| 参数 | Big（大阀） | Small（小阀，默认） |
|---|---|---|
| 开侧极限 `open_lim_x10` | `3`（0.3°） | `40`（4.0°） |
| 关侧极限 `close_lim_x10` | `CLOSE_LIMIT_X10` | `1050`（105.0°） |
| 目标下限 `tgt_min_deg` | 3° | 4° |
| 目标上限 `tgt_max_deg` | 95° | 105° |
| 驱动速度 `drive_spd` | `MAX_SPEED` | 40 |
| 限位拉回速度 `lim_spd` | 45 | 40 |

闭环死区 `DEADBAND_X10 = 10`（1.0°），到位后需超出"死区 + `INPOS_RELEASE_X10`"才重新驱动，用于抑制棘轮回弹造成的反复启停。

## 目录结构

```
JingXiaxianmu/
├── applications/        主程序框架 (main.c)
├── UserInc/ UserSrc/    板级初始化、Modbus 从站、中断服务
│   ├── Init.c           时钟/GPIO/DAC/ADC/DMA/USART 初始化 + 串口中断
│   ├── ModBus.c         U3 Modbus RTU 从站协议处理
│   └── Define.c/h       全局数据结构定义
├── HardwareInc/ HardwareSrc/
│   ├── Motor.c          电机方向/调速、角度闭环、过载保护
│   ├── Pressure.c       ADC 滤波、压力换算、过载与卡滞检测
│   └── RS485.c          U2 编码器总线服务线程（唯一持有者 + 消息队列）
├── project.uvprojx      Keil MDK 工程
├── rtconfig.h           RT-Thread 裁剪配置
└── LICENSE              Apache License 2.0
```

### 软件架构要点

- **U2 总线单一持有者**：`RS485.c` 里运行唯一的编码器服务线程（优先级 9），其它线程/命令只能通过 `rt_mq` 投递请求，避免多线程抢总线把 Modbus 帧拆碎。服务线程优先级必须**高于**主循环，否则发送期间被抢占会让帧内字节间隔超过 1.5 字符时间，从站直接丢帧。
- **角度数据走缓存**：主循环每 10ms 读 `tAngleControl.Angle_Current_x10`，超过 500ms 未刷新则判定编码器失联并停电机。
- `rt_kprintf` 不支持 `%f`，角度与压力统一用整数放大方式打印。

## 编译

工具链：**Keil MDK 5 + ARMCC v5.06**。

工程文件的 Include Path 与源文件列表引用了仓库**同级**的 `SDK` 目录（82 个源文件中有 68 个位于该目录），因此需要保持如下目录结构：

```
stm32l4_example/
├── JingXiaxianmu/          ← 本仓库
└── SDK/
    ├── rt-thread/          RT-Thread 4.0.1 源码
    ├── libraries/          CMSIS + STM32L4xx HAL Driver
    └── drivers/            板级驱动 (drv_gpio / drv_usart ...)
```

用 Keil 打开 `project.uvprojx` 后直接 Build 即可。

> 修改 `Drivers` 或 RT-Thread 配置时注意：`rtconfig.h` 中被禁用的串口，其 `HAL_UART_MspInit` 结尾有 `RT_ASSERT(0)`，若自行初始化该串口需要一并处理。

## msh 调试命令

| 命令 | 说明 |
|---|---|
| `Motor CW\|CCW\|STOP Speed<0-100>` | 手动强制驱动电机（**绕过闭环与保护，仅调试用**） |
| `MotorControl <deg>` | 设置闭环目标角度 |
| `ValveCfg Big\|Small` | 切换阀门配置（量程/速度） |
| `Read Angle` | 读编码器角度（读缓存） |
| `WriteAngle <0-360>` | 写编码器角度值 |
| `Sensor Reset` | 编码器零点重置 |
| `Press` | 打印两路压力 |
| `AdcDbg` | 打印 ADC 原始值/滤波值/零点/校准状态 |
| `PressMon [count]` | 每 200ms 打印压力与峰值 |
| `PressBase` | 顶到极限后，把当前运行峰值标定为标称压力 |
| `PressBaseSet <P1> <P2>` | 手动设置标称压力（0.01MPa，0=该路禁用） |
| `LifeDbg` | 打印寿命/卡滞检测状态、过载方向与峰值 |
| `ProtectReset` | 清除过载故障与目标保持 |
| `DAC <0-3.3>` | 直接输出 DAC 电压 |

## 已知问题

- `HardwareSrc/Motor.c`、`HardwareSrc/Pressure.c`、`UserSrc/ModBus.c`、`UserInc/Define.h` 为 **GBK 编码**（Keil 默认），在 GitHub 网页上查看中文注释会显示乱码；用 Keil 打开，或把编辑器编码切成 GBK/GB2312。
- msh 的 `Motor CW|CCW` 直接操作电机，**不经过**闭环与过载保护。
- 过载保护当前在主循环里每 10ms 检测一次，压力上升极快时存在毫秒级响应延迟。
